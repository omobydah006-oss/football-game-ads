# ⚽ Football Game with Ads

لعبة كرة قدم احترافية مع نظام إعلانات متكامل - جاهزة لـ Google Play Store

## 🎮 المميزات

- ✅ لعب كرة قدم تفاعلي
- 📺 إعلانات عند الخسارة (Rewarded Ads)
- 🎯 نظام نقاط ولاعبين
- 🎨 تصميم جميل وسلس
- 📱 متوافق مع جميع الهواتف

## 🛠️ التكنولوجيا

- **Engine**: Unity 2022 LTS
- **Language**: C#
- **Ad Network**: Google Admob
- **Target**: Android (Google Play Store)
